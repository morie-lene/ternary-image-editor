# 三値画像修正GUIツール

原画像と三値画像を同一座標で重ねて確認し、三値画像だけを画素単位で修正して別保存する Windows 用デスクトップアプリケーション。

現在の要求正本は [開発仕様書 v1.5](docs/ternary_image_editor_spec_v1_5.html)。
[開発仕様書 v1.1](docs/ternary_image_editor_spec_v1_1.html) は履歴として残すが、現行判断には
用いない。実装状況と検証層は [要求追跡表](docs/requirements-traceability.md)、仕様未規定の
採用判断と同一性境界は [設計判断](docs/design-decisions.md) に分離して記録する。

## 開発環境

対象実行環境は Python 3.11.x。依存と仮想環境は `uv` で固定する。

```powershell
uv sync --python 3.11
uv run ternary-image-editor
```

macOS/Linuxでも開発確認には同じ入口を使えるが、配布対象と最終受入環境はWindows
10/11である。

## 基本操作

1. 「フォルダ選択」で原画像、入力三値画像、編集済み画像出力の三フォルダを指定する。
2. 一覧から画像対を開く。既存出力がある場合は、編集済み版から続けるか入力版から
   始めるかを選ぶ。
3. 原画像の重畳、不透明度、疑似色、格子を表示欄で調整し、筆・塗り潰し・境界生成で
   三値ラベルだけを変更する。選択色は直接指定または順・逆循環で切り替えられる。
4. 「保存」または `Ctrl+S` で出力フォルダへ検証付きPNGを保存する。画像移動や終了時は
   未保存変更の保存・破棄・中止を明示選択する。
5. 「設定」から表示初期値、疑似色、筆・境界初期値と主画面38操作の主・副キー割当を
   変更する。本文中のキーは既定値であり、固定入力ではない。

画像外と下端100行（`y=1436..1535`）は編集されない。下端は読込時と保存時にも「無」へ
正規化され、読込時に差分があれば未保存になる。低倍率で筆の画面径が4機器画素未満なら
筆描画を止める。筆は画素へ離散化した `D×D` マスクを用い、描画中の他命令は実行も予約も
しない。Esc・非活性化・捕捉喪失では筆跡全体を取り消す。
小領域強調、疑似色、格子、原画像、筆ポインタは表示専用であり、出力へ混入しない。
三値画像を非表示にしている間は画素編集とUndo・Redoも停止する。

試験と静的検査:

```powershell
uv run pytest
uv run ruff check .
```

## データ境界

- 原画像と入力三値画像は読取専用で、アプリケーションから上書きしない。
- 原画像は8-bit `L` / `RGB`だけを受理し、ICC付き画像は表示用にsRGBへ変換する。
  アルファ、索引色、CMYK、16-bit、EXIF Orientation 2〜8は拒否する。
- 編集正本は `uint8` 二次元配列のラベル `0 / 1 / 2`。
- 未保存判定は履歴位置ではなく、読込時または正常保存時に確定した基準配列との内容比較。
- 表示像、疑似色、格子、警告、筆ポインタを保存元にしない。
- 出力は一時PNGを再検査してから `os.replace` で置換する。
- 原画像・入力三値画像・出力の外部変更をSHA-256で検査し、対象出力ごとの排他的な
  保存ロックを検査から置換まで保持する。同じロック規約に従う本アプリ多重起動間は排他
  できるが、ロックに従わない別アプリとの条件付き置換までは保証しない。

## 現在の受理境界

macOS 上の開発試験と Windows 上の最終受理を分ける。Windows 10 / 11、表示倍率
100 / 125 / 150 / 200%、日本語入力方式とWindows配列での論理キー表示、複数起動、
対象業務PCでの性能、配布物起動は Windows 実機での最終確認事項であり、ローカル試験成功
だけで受理済みとは扱わない。

現在の自動試験と実寸性能値は
[ローカル検証記録](docs/local-verification-2026-08-18.md)に固定してある。

未保存編集の異常終了後の自動復元は初期版の対象外である。正式出力は原子的置換で守るが、
保存前の作業配列は失われ得る。

## Windows配布候補

Windows上で次を実行すると、試験と静的検査の後にPyInstallerのone-folder配布候補を作る。
構築スクリプトは旧候補を限定削除し、生成exeの配置、非零長、MZ先頭、一意性、
SHA-256を検査してから成功表示する。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build_windows.ps1
```

成果物は `dist/TernaryImageEditor/TernaryImageEditor.exe`。配布判断前に
[Windows最終受入チェックリスト](docs/windows-acceptance-checklist.md)を埋める。構築時には
同じ配布フォルダの `docs/` へv1.5要求正本を複製し、固定SHA-256も検査する。
