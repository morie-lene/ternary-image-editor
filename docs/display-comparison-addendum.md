- 文書ID: `TIE-ADD-DISP-CMP-001`
- 文書版: `1.0`
- 制定日: `2026-08-19`
- 基線仕様: `docs/ternary_image_editor_spec_v1_5.html`
- 基線SHA-256: `ed267bde1634072f1e3249d0c7d0670cdec1dbd08e3130380844cff492c0c497`
- 初回実装版: `0.6.0`
- 規範状態: 現行

## 1. 目的と適用関係

本追補は、表示中の三値画像と原画像を「比較（暗）」で合成する表示切替を追加する。画素編集、
三値化、入力検査、保存色、保存形式は変更しない。

基線仕様v1.5の7.2、7.3、7.4、13.2、15.7、21.2のうち、表示合成方式、表示設定、操作件数に
関する部分だけを本追補が限定上書きする。ほかの要求は基線仕様を維持する。
`TIE-ADD-FLEX-001`の入力・対応付け・保存済み出力再開と、`TIE-ADD-PTR-001`のマウス入力割当は
本追補の対象外であり、互いの規範範囲は交差しない。

## 2. 用語と同一性境界

- `T`: 現在表示する三値画像のRGB。疑似色が無効なら保存色、疑似色が有効なら現在の疑似色を使う。
- `O`: 表示方向を反映した原画像のRGB。
- `alpha`: 原画像不透明度を0以上1以下へ換算した値。
- 比較（暗）状態: 表示合成方式を選ぶ永続的な真偽値。
- 画像内容: 編集対象のラベル配列、内容基準、Undo・Redo履歴、入力・出力ファイル。

比較（暗）状態、画面上のチェック部品、操作ID、画像内容は別の物である。チェック部品と操作は
同じ状態を変更する入口だが、いずれもラベル値そのものではない。

## 3. 規範要求

### DISP-CMP-001 常設表示切替

主画面の表示欄へ「比較（暗）」チェック欄を置く。無効と有効を一操作で切り替え、現在状態を
チェック表示する。機能が表示だけに作用する旨を補助説明で示す。

### DISP-CMP-002 操作同一性

操作ID `view.toggle-darken-comparison` を、表示名「比較（暗）を切り替える」、型`SINGLE`として
操作台帳へ加える。既定の主・副割当はともに空とし、設定画面から既存の鍵盤・マウス割当規則で
割当可能にする。基線仕様の38操作へ本操作を一件だけ加え、現行操作総数を39とする。

### DISP-CMP-003 既定無効と従来表示

既定値は無効とする。無効時は基線仕様の表示を画素単位で維持する。

- 疑似色無効: 保存色の三値画像を基底とする従来の比較（明）合成。
- 疑似色有効: 疑似色画像を基底とする従来の通常合成。

有効から無効へ戻した時も、同じ表示設定なら初回の無効表示へ戻らなければならない。

### DISP-CMP-004 比較（暗）の画素式と解像度

有効かつ両画像が表示対象で`alpha > 0`の時、原解像度の各画素・各RGB成分について次を計算する。

```text
M = min(T, O)
D = (1 - alpha) * T + alpha * M
```

完成した一枚の原解像度画像を表示倍率へ拡縮する。合成前に各画像を別々に拡縮してはならない。
`alpha = 0`では`T`、`alpha = 1`では`min(T, O)`と完全一致する。中間値は8-bit描画器の不透明度
量子化を含み、上式を最近傍整数化した値との差を各成分2以下とする。

### DISP-CMP-005 保存色・疑似色の共通適用

比較（暗）は疑似色の有無にかかわらず適用する。疑似色有効時の`T`は現在の疑似色設定であり、
保存色へ戻して比較してはならない。切替によって疑似色設定またはラベル配列を変更しない。

### DISP-CMP-006 非表示層と不透明度

- 三値画像だけを表示する時、比較（暗）の有効・無効で画素を変えない。
- 原画像だけを表示する時、比較（暗）の有効・無効で画素と透明度を変えない。
- 両画像を非表示にした時、比較（暗）によって画像内容を生成しない。
- 原画像不透明度が0の時、原画像の内容を表示へ混入させない。

### DISP-CMP-007 表示専用性

比較（暗）の切替、設定適用、再起動復元は、ラベル配列、内容基準、履歴、改訂番号、未保存判定、
入力ファイル、既存出力、次回保存PNGを変更してはならない。表示用画像の再生成と表示状態の永続化
だけを許す。

### DISP-CMP-008 永続化と設定取引

設定名を`darken_comparison_enabled`、QSettings keyを`view/darkenComparison`とする。欠損時または
不正値時は`false`へ退避する。設定画面の「適用」または「OK」で主画面・表示・永続値へ反映し、
「取消」では開く前の適用済み状態を変えない。既存schema 2へ既定可能な真偽値を加えるだけとし、
schema番号は変更しない。

## 4. 非目的

- 入力画像を三値化または暗化して保存すること。
- 原画像または三値画像の色空間、寸法、Orientation、対応付け規則を変えること。
- 比較（暗）を新しい編集道具、選択ラベル、履歴操作として扱うこと。
- 既定の鍵盤またはマウス割当を新たに占有すること。
- Windows実機の色再現または高DPI表示を局所自動試験だけで受理すること。

## 5. 証拠と最終受理

公開受入試験`tests/test_display_comparison_contract.py`は、DISP-CMP-002から008までの局所的な
画素・状態・永続化契約を再現する。操作盤、設定画面、操作台帳、主画面、包装の回帰試験は
DISP-CMP-001から008の接続を補う。

自動試験はWindows実機の描画、機器画素比、GPU・描画器差、対象業務PC性能を受理しない。
Windows配布候補上の最終判断は`docs/windows-acceptance-checklist.md`へ記録し、人間が
`accept / reject / hold`を決める。
