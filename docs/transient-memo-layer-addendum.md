## 1. 目的と適用関係

本追補は、画像を保存内容へ混入させず一時的に書き込むメモ層を追加する。メモは主画像の
最上段に見える注記だが、ラベル値、原画像、入力ファイル、出力PNGの一部ではない。
本書の`MEMO-*`は実装が満たすべき状態であり、現在の動的保証やWindows受理を単独では
主張しない。実装・自動証拠・未受理事項の現在状態は要求追跡表で別管理する。

マウス入力割当追補5節のうち、未割当の右buttonへ固定操作を加えないという記述を、本追補が
一時メモ入力に限って上書きする。同追補の完全一致割当、Canvas限定、押下・解放、HOLD解放の
規則は維持する。また、基線仕様のAT-065にある三値非表示時のUndo・Redo停止を、次の履歴項目が
メモ差分だけを持つ場合に限って上書きする。ほかの入力、編集、保存、遷移、表示要求は基線仕様と
既存追補を維持する。

version 1.1は基線の設定画面にメモ生成可否と記入色を追加し、既存の
`app.open-settings`操作の表示名と配置だけをMEMO-010〜011の条件で上書きする。
操作ID、既存割当、その他の設定要求は維持する。

本追補の要求身元は`MEMO-*`、受入条件は`MEMO-AT-*`とする。基線の`AT-*`、柔軟入力追補の
`FLEX-AT-*`、マウス入力追補の`PTR-AT-*`、表示比較追補の`DISP-CMP-*`とは同じ要求ではない。

## 2. 用語と同一性境界

| 対象 | 意味 | 混同しない物 |
| --- | --- | --- |
| メモ画素 | 現在の画像セッションだけに属する透過色付き上描き画素 | ラベル値、疑似色、原画像、保存PNG |
| メモ一筆 | 右button押下から正常解放までに生じた一回のメモ差分 | 一画素、一移動event、メモ層全体 |
| ラベル差分 | 黒・灰・白のラベル配列を変える可逆差分 | メモ差分、表示設定、未保存判定 |
| 履歴項目 | 一回の利用者操作。ラベル差分、メモ差分、または両方を持つ | 画像内容基準、履歴配列上の位置 |
| `memo-only` | メモ差分を持ち、ラベル差分を持たない履歴項目 | メモを含む複合履歴項目 |
| `label-containing` | ラベル差分を持つ履歴項目。メモ差分の有無は問わない | 現在画素が保存基準と同じかどうか |
| 未保存状態 | 現在ラベルと内容基準の比較、および既存の取込要保存状態 | メモの有無、履歴項目数、履歴位置 |

メモとラベルは保存所属が異なるが、Undo・Redoの時系列は共有する。別のメモ履歴を置いて二つの
時系列を後から併合してはならない。

## 3. 規範要求

### MEMO-001 右button完全一致の優先

主画像Canvas上で正規化した右button tokenを得た時、修飾キーを含めて完全一致する割当があれば、
マウス入力割当追補どおり割当操作を優先し、メモを開始しない。割当操作がその時点で無効でも
メモへfallbackしない。

完全一致する割当がない右button tokenは、MEMO-010のメモ生成設定が有効な場合だけ固定メモ入力とする。
無効な場合はメモを開始しない。右buttonを操作へ割り当てる設定変更では、その完全一致tokenの固定
メモ入力が置換されることを適用前に示し、続行または取消を選ばせる。別の修飾tokenへ割当があっても、
未割当の完全一致tokenまで奪わない。メモ生成設定の有効・無効は、完全一致する割当操作の優先と
実行可否を変えない。

### MEMO-002 最上段の非保存表示

メモは原画像、三値画像、疑似色、比較合成、格子、小領域強調より後に描く最上段の画像注記とする。
入力位置を示す操作ポインタとwindow部品はメモ画素ではない。三値画像を非表示にしてもメモ層は
自動で消さない。

メモ画素はラベル配列、内容基準、画像改訂番号、小領域解析、入力・出力の内容指紋、保存PNGを
変更しない。メモだけの追加・取消・Undo・Redoによって未保存状態へ移らず、画像移動または終了の
未保存確認を発生させない。

### MEMO-003 一筆の原子性

未割当の右button押下でメモ一筆を始め、移動を補間し、正常解放で一履歴単位として確定する。
移動しない押下・解放も一点の一筆として扱う。画素ごと、移動eventごと、メモ層全体を一履歴単位に
してはならない。

一筆中のEsc、window非活性化、焦点喪失、マウス捕捉喪失、描画例外では、その一筆が触れたメモ画素を
押下前へ戻し、履歴を作らない。一筆の完成または取消まで、ほかの命令は発火も予約もしない。

### MEMO-004 単一履歴時系列

メモ一筆、ラベルだけの編集、ラベルとメモの複合編集を、一つの履歴列へ操作発生順に積む。
Undo・Redoはこの列の隣接項目だけを適用し、種別の違う項目を飛び越さない。Undo後にメモまたは
ラベルの新しい操作を確定した時は、種別を問わず同じRedo枝を破棄する。

メモ差分は変わった画素の索引と前後値だけを保持する。メモ項目の操作数と差分byte数を既存の
200操作／512 MiB上限へ算入し、全画面複製や上限外の別履歴を置かない。

### MEMO-005 ラベル編集との重複

ラベル筆が通った幾何学的な筆跡範囲にメモ画素があれば、ラベルが同色で変わらない画素を含めて
メモを消す。ラベル差分とメモ消去差分は同じ履歴項目へ束ねる。ラベル差分がなくメモだけを消した
場合も、一回の可視変更として履歴を作る。

ラベル筆を取り消した時は、同じ一操作で消したメモも復元する。Undoはラベルとメモを同時に操作前へ
戻し、Redoは両方を同時に再適用する。下端保護などによりラベル筆自体を拒否した範囲ではメモを
消さない。筆跡範囲を持たない編集算法は、実際にラベルが変わった画素だけを重複範囲とする。

### MEMO-006 三値非表示時のUndo・Redo

三値画像を非表示にしている間も、次のUndoまたはRedo項目が`memo-only`なら、その一項目を適用できる。
次項目が`label-containing`なら操作を停止する。さらに奥の`memo-only`項目を探索して飛び越しては
ならない。三値画像を再表示すれば、同じ先頭項目から通常のUndo・Redoを再開できる。

### MEMO-007 保存境界

保存処理へ渡す画像はラベル配列だけから作り、メモを含めない。正常保存が確定した時だけ、現在の
メモ画素と履歴中の全メモ差分を破棄する。`memo-only`項目は除き、複合項目はラベル差分だけへ縮退
させる。保存前からあるラベルUndo・Redo能力は保ち、保存後のUndoでメモを再出現させない。

保存失敗、外部変更確認の中止、上書き確認の取消では、メモ画素、履歴列、Undo・Redo位置を維持する。
保存開始後から成功または失敗が確定するまで、新しいメモ一筆を開始しない。

### MEMO-008 画像交換境界

別の画像対または別の対応計画を正常に導入した時、旧画像のメモ画素と履歴を破棄し、新画像のメモ層を
空で始める。読込失敗、JPEG確認の取消、未保存確認の中止、全候補失敗、対応計画の取消では現在画像を
交換せず、現在のメモ画素と履歴位置を維持する。

### MEMO-009 メモ内容を永続化しない

メモ画素とメモ履歴を、PNG、QSettings、側車file、回復file、clipboard、外部logへ永続化しない。
異常終了後または応用再起動後のメモ内容復元は保証しない。MEMO-010の生成設定と記入色は利用者設定で
あり、この非永続境界には含めない。新しいnetwork通信、telemetry、権限、依存packageを追加しない。

### MEMO-010 メモ生成と記入色の利用者設定

設定画面へ「右クリックで一時メモを描画」の有効・無効と、記入色を置く。既定は有効、既定色は
`#FFD640`とする。記入色は`#RRGGBB`だけを受理し、色選択部品と既定復元を備える。
有効・無効をQSettingsの`memo/enabled`、記入色を`memo/color`へ保存し、再起動後に復元する。
欠損値または不正値は各既定値へ退避する。

適用またはOKはその場で設定を反映し、取消は未適用の変更を破棄する。有効・無効は以後の未割当
右buttonによる生成だけを制御し、既存メモの表示、画素、履歴を変更しない。記入色は適用後に始める
一筆と、メモ入力を示す操作ポインタへ反映する。既に描いたメモ画素と履歴中の前後値を再着色しない。
メモの黒い外線と透過度は固定し、利用者色は内線のRGB成分だけへ用いる。設定の適用、取消、復元は
ラベル、内容基準、画像改訂番号、未保存状態、Undo・Redo位置を変更しない。
画面反映またはQSettings保存に失敗した場合は適用済み設定を更新せず、画面と永続値の両方を
適用前の値へ復元する。復元自体に失敗した場合は、復元失敗を利用者へ明示する。

### MEMO-011 設定入口

設定操作は表示名を「設定」とし、file menu内へ置かず、menu bar上でhelp menuの直前に独立actionとして
置く。既存の主toolbarとcontrol panelからの設定入口は維持する。既存の`app.open-settings`操作を
各入口で共有し、入口ごとの操作IDや処理を増やさない。

## 4. 非目的

- メモを画像ラベル、選択範囲、解析入力、保存形式へ変換すること。
- メモ専用fileの保存・読込、複数画像間の持越し、異常終了後の自動回復。
- メモ専用の操作ID、径・形状・外線・透過度の利用者設定、既存メモの一括再着色。
- メモ生成設定を既存メモの表示切替または削除命令として扱うこと。
- 履歴をメモ列とラベル列へ分離し、都合のよい項目だけを飛び越してUndo・Redoすること。
- 局所自動試験だけでWindows実マウス、DPI、描画器、配布候補の受理を閉じること。

## 5. 受入証拠とWindows判断門

公開`tests/test_transient_memo_layer_contract.py`は、完全一致割当の優先、最上段描画、単一履歴、
複合項目、保存・画像交換の成功専用破棄、失敗維持、三値非表示時の次項目門、履歴上限への算入、
メモ生成・色設定の永続境界、設定入口を接続契約として検査する。この試験は動的な画素・Qt event試験を
置換せず、Windows実機受理も閉じない。
